# Pet Match: Zoo Puzzle

Fragen, ein Problem oder eine Idee? Schreiben Sie an **7tam.official@gmail.com**. Wir beantworten jede Nachricht, meist innerhalb von zwei Tagen.

- **Käufe wiederherstellen** auf einem neuen Telefon oder nach einer Neuinstallation: Tippen Sie oben im Spielbildschirm auf die Zahnrad-Taste und dann auf „Käufe wiederherstellen“.
- **Abonnements:** Verwalten oder kündigen Sie sie in iOS unter Einstellungen > [Ihr Name] > Abonnements.
- **Ihr Fortschritt** wird auf Ihrem Gerät gespeichert und, wenn Sie bei iCloud angemeldet sind, in Ihrem eigenen iCloud-Account, sodass er auf einem neuen iPhone oder iPad zurückkommt.
- **Werbung** beginnt ab Level 20. „Keine Werbung“ entfernt Banner und Vollbildwerbung.
